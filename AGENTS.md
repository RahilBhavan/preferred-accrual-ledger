Use the installed **rahil-design** skill before creating or changing public figures, pages, screenshots, diagrams, demo UI or promotional artifacts. Its canonical Operations Hub bundle is `.agents/skills/rahil-design/SKILL.md`; read its design, voice and checks references. Keep it synchronized deliberately; do not invent another palette or font pairing. If the skill is unavailable, follow that contract and report the limit.

The reconciliation SVG and responsive HTML table are light quantitative artifacts. Keep unresolved gaps and the funding-versus-settlement distinction visible.

Preserve the existing calculation/protocol behavior, factual claims, provenance and financial snapshot. Never restyle a failure, missing input or skipped check into a success. Render changed visual artifacts at desktop and 400px widths; check overflow, contrast, keyboard/focus and reduced motion where relevant. State font fallbacks honestly. Run the repository's documented checks before committing. CLI-only work does not need a new UI.

Do not add licenses for project code, real account data, public-chain activity, deployments, recurring automation or outbound messages through a design task. Publication authorization must come from the user/session.
